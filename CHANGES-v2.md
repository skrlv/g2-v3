# Доработка дизайна и UX (v2, сентябрь 2026)

Правки поверх `g2-fixed`. Проверено: `npm run typecheck`, `npm run lint`, `npm run build`,
прогон всех страниц на 1440px и 390px в headless Chromium, корзина, мобильное меню.
Схема базы и API не менялись — обновление сводится к замене файлов и деплою.

## Что изменилось и зачем

### Сетка и мобильная версия
- **Две колонки товаров на телефоне.** Брейкпоинт `xs` был 416px, поэтому все обычные телефоны
  (375–430px) получали одну колонку и каталог растягивался на 6 экранов. Теперь `xs = 360px`
  (`globals.css`), на телефоне две колонки с зазором 12/32px; одна колонка остаётся только
  на очень узких экранах. Каталог стал вдвое короче, подпись карточки на телефоне — 12px.
- **Категории на главной** — три колонки на десктопе вместо четырёх: шесть категорий ложатся
  в два ровных ряда, а не 4 + 2.

### Герой
- Четыре декоративные линии внизу читались как индикатор слайдера, но ничем не были.
  Теперь это **индекс разделов** (`section-index.tsx`): штрих + номер + название,
  клик прокручивает к «Поступлениям», «Позиции» и «Категориям» (Lenis или нативный скролл).
  На телефоне скрыт — там остаётся кнопка «Вниз».
- Рядом с «Смотреть каталог» появилась тихая ссылка «О бренде»: у первого экрана есть
  второе действие без второй кнопки.

### Карточка товара
- **Размеры показываются при наведении** (только на устройствах с мышью — `group-hover`
  в Tailwind v4 не срабатывает на тач-экранах). На телефоне панель по-прежнему открывает «+».
  Быстрое добавление в корзину — один клик вместо двух.
- **Второй кадр при наведении** больше не подставляет общую фактуру-заглушку
  `texture.jpg`: раньше при наведении вещь исчезала и показывался бетон. Константа
  `PLACEHOLDER_IMAGE` в `lib/catalog.ts`; когда у товара появится настоящее второе фото,
  оно будет показываться как раньше.

### Корзина
- **Линейка до бесплатной доставки** под итогом: «До бесплатной доставки — 16 100 ₽ · 36 %»
  и тонкая шкала, при достижении — «Доставка по России бесплатно». Порог вынесен в
  `FREE_SHIPPING_CENTS` (`lib/catalog.ts`) и используется в тексте на странице товара —
  одно место для изменения.

### Шрифты
- Oswald и Inter лежат в репозитории (`src/app/fonts`, OFL) и подключены через
  `next/font/local` вместо `next/font/google`. Сборка больше не ходит в Google Fonts —
  на CI или хостинге, где `fonts.googleapis.com` недоступен, сайт раньше собирался
  с системным шрифтом вместо Oswald. Оба файла — variable, субсет latin + cyrillic.

### SEO и служебное
- `robots.txt` (`/admin` и `/api` закрыты) и `sitemap.xml` (разделы + все опубликованные
  товары из базы) — `src/app/robots.ts`, `src/app/sitemap.ts`.
- **Картинка для соцсетей** (`src/app/opengraph-image.tsx`): знак G2, слоган и координаты
  на фоне void, рендерится на сервере. Страницы товаров по-прежнему отдают фото товара.
  Для standalone-сборки шрифты картинки включены через `outputFileTracingIncludes`.
- `favicon.ico` рядом с `icon.svg` — часть браузеров и мессенджеров запрашивают именно его
  (в логах был 404).
- `loading.tsx` — состояние загрузки маршрута в стиле шторки («G2 / Загрузка») вместо
  пустого экрана, пока страница читает каталог из базы.
- Студия `/admin` закрыта от индексации (`admin/layout.tsx`, `robots: noindex`).
- Доступность: ссылка «К содержимому» для клавиатуры (видна по Tab), `aria-current="page"`
  на активном пункте навигации, canonical и `siteName` в метаданных.

## Что не трогал
- Схема базы, API, студия, оформление заказа, Telegram-уведомления.
- Фото товаров и тексты: второй кадр `texture.jpg` в галерее — это контент, его заменит
  владелец через студию.

## Как обновиться
1. Заменить файлы проекта содержимым архива, `npm install` не нужен (зависимости те же).
2. `npm run build && npm start` или деплой как обычно (см. `DEPLOY.md`).
3. Проверить, что задан `NEXT_PUBLIC_SITE_URL` — он попадает в `sitemap.xml`, `robots.txt`
   и абсолютные ссылки Open Graph.
