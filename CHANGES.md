# Что изменено (сентябрь 2026)

Исправления по итогам разбора кода. Дизайн не менялся. Проверено: `npm run typecheck`,
`npm run lint`, `npm run build` (в том числе без `DATABASE_URL`), прогон страниц и API.

## Как обновиться

1. Замените файлы проекта содержимым этого архива и сделайте коммит / деплой.
2. На хостинге проверьте переменные (подробно — в `DEPLOY.md`, раздел 1):
   - `ADMIN_PASSWORD` — **теперь обязателен на проде**: без него студия отвечает «выключена»;
   - `NEXT_PUBLIC_SITE_URL` — адрес сайта для превью в соцсетях;
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — по желанию, уведомления о заказах и сообщениях.
3. База обновится сама при первом открытии сайта: добавятся поля заказа `phone` и `status`,
   таблица `settings`, валюта товаров приведётся к рублям. Данные не удаляются.
   Перед деплоем всё равно сделайте бэкап (`pg_dump`, см. `DEPLOY.md`).

## Студия `/admin`

- Загруженные фото больше не ломаются при сохранении (строка картинок резалась по запятой).
- Правка цены существующего товара теперь сохраняется; цена обязательна.
- Новый товар с уже занятым адресом (slug) не затирает старый — будет сообщение об ошибке.
- Удаление и «Добавить из файла контента» — с подтверждением; переход на другой товар
  предупреждает о несохранённых правках.
- «Добавить из файла контента» добавляет только отсутствующие товары и не трогает
  отредактированные. Перезапись всего — `POST /api/seed?overwrite=true`.
- Новые вкладки: **Заказы**, **Сообщения**, **Подписки**.
- Ссылка «Студия» из подвала сайта убрана — открывайте `/admin` напрямую.

## Заказ

- В корзине: email, телефон (обязателен), имя, адрес или комментарий.
- Сервер проверяет товары и размеры и сообщает покупателю, что не так, вместо молчаливой
  подмены размера; покупатель видит номер заказа и сумму.
- Честный текст: «мы свяжемся, подтвердим наличие и пришлём способ оплаты» вместо
  «инструкция по оплате отправлена». Строка «Демо-оформление» убрана.
- Номер заказа вида `G2-XXXXXXXX-XXXX`, без коллизий.
- Уведомление владельцу в Telegram (если заданы переменные).
- На телефоне нижняя панель «В корзину» кладёт выбранный размер, а не первый из списка.

## Защита

- Студия, загрузка фото, синхронизация, изменения товаров и список с черновиками закрыты
  паролем; без пароля на проде — 503, а не открытый доступ. Пароль с кириллицей работает.
- Запросы на изменение с чужих сайтов отклоняются (CSRF).
- Черновики не открываются по ссылке и не попадают в заказ.
- Формы заказа, контактов и подписки: лимит запросов с одного адреса, ограничения длины,
  скрытое поле-ловушка для ботов.
- Ошибки базы не уходят покупателю — только в лог сервера.

## Техническое

- Одна валюта магазина (RUB) — константа `STORE_CURRENCY` в `src/lib/catalog.ts`.
- Подключение к базе ленивое: `next build` и сборка Docker-образа работают без `DATABASE_URL`.
- `middleware.ts` → `proxy.ts` (Next.js 16).
- Небольшие миграции схемы выполняются при старте (`src/db/bootstrap.ts`); стартовый каталог
  засевается один раз и не возвращается, если каталог опустошить.
- Фото из студии больше не попадают в корзину (localStorage) и в заказы; в карточки каталога
  уходит только нужное.
- 3D-просмотрщик освобождает ресурсы при уходе со страницы; 3D-блок показывается только у
  товаров с моделью. Демо-товар «Объект Монолит», его модель и скрипт удалены.
- Убраны иконки поиска и аккаунта (вели не туда), заглушка домена, опечатки, «© 2025».
- `drizzle.config.json` → `drizzle.config.ts` (адрес базы из `DATABASE_URL`).
